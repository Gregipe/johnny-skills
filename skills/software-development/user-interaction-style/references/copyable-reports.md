# Copyable Reports

When Greg asks for a "test report" or "report to copy", deliver a clean, self-contained markdown block he can paste directly into another conversation. No preamble, no "here's the report", no verbal wrapping.

## Format

- Markdown with proper headers, tables, and checkmarks
- Self-contained (the advisor can read it without prior session context)
- Honest about false negatives, infra issues, and known limitations
- Numerical where possible (X/Y passed, section scores)

## Triggers

- "give me report for me to copy"
- "send me the test report"
- "could you send a test report for the advisor"
- "send me the test report for me to copy"

## Delivery

Put the report block immediately after the user's request with zero conversational filler. If a one-line note is needed, put it AFTER the block.
