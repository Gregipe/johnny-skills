# Ava/Dashboard Response Formatting (2026-06-16)

Greg wants clean, scannable responses from Ava — he reads on mobile (WhatsApp/dashboard).

## Section Headers

Every section must have a bold header: `*Header Name*`

## Action Items — Always Show Three Things

Each action item must display:
1. Description — what needs to be done
2. Lead name — tagged as "— Lead Name"
3. Due date — tagged as "⏰ Date Time"

Example: `• Check in on team — Prashant Rai | ⏰ Jun 17 at 7:00 PM`

## Section Order for Multi-Item Responses

```
*🔴 OVERDUE*
• Action — Lead (due Jun 16)

*⏳ PENDING*
• Action — Lead | ⏰ Jun 17 at 6:00 PM

*✅ ACCOMPLISHED TODAY*
• Action — Lead

*📚 TODAY'S LEARNINGS*
• Title: summary
```

## Status Icon Legend

- ✅ completed or resolved
- ⏳ pending or in progress
- 🔴 overdue (past due date, not yet completed)

## Multi-Step Plans

When proposing multiple actions:
```
Here's the plan:
*Step 1/3:* Create deal
*Step 2/3:* Attach contact
*Step 3/3:* Set reminder
```

## Hard Rules

- No ASCII art
- No emoji-only lines without accompanying text
- Maximum one blank line between sections
- Use `•` bullets, not `-` or `>`
- No walls of text — max 3-4 lines per paragraph

## Morning Briefing Format

The end-of-day briefing (generated by `__morning_briefing__` in server.py ~line 8870) must show:
- OVERDUE: past-due actions (due_at < now, not completed)
- PENDING: upcoming actions
- ACCOMPLISHED TODAY: completed/resolved today
- TODAY'S LEARNINGS: learning_notifications from today only

Not a random dump of all actions ever created.
