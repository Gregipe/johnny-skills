## Component Architecture

### Sidebar (`class="sidebar"`)
- Fixed width 240px, gray background (#F5F5F7)
- Header: AR logo (36px black square) + "Autonomous Revenue Agent v1.0"
- Nav items: emoji icons + labels, hover/active feedback (#E8E8ED / #E0E0E5)
- Sections separated by 8px margins and uppercase section titles
- Footer: User avatar (G) + name/role

### Stats Grid (`class="stats-grid"`)
- 4-column grid: Leads Today, Leads Engaged, Meetings Booked, Revenue Closed
- Each card: label (11px uppercase) + value (28px bold) + change text

### Dashboard Cards (`class="dashboard-card"`)
- Two-column grid for Needs Your Attention + Avg Turnaround
- Full-width card for Channel Performance (pie chart + legend)
- Full-width for Recent Leads table

### Leads Table (`class="leads-table"`)
- Columns: Name (with email sub), Account (with phone), Source, Status badge, Last Activity, Next Action
- Rows clickable via `.lead-row` class + event delegation
- Data: fetch from `/api/tenants/{id}/leads`

### Lead Detail Page (dynamic, rendered by `showLeadDetail()`)
- Breadcrumb: Leads > Name
- Lead header: Name + "Hot" pill + subtitle (title · company · email · phone)
- Action buttons: Start AI Chat, More, ← Prev, Next →
- 4-column info card: Lead Metadata, Company, Contact, AI Summary
- Tab bar: Timeline, Profile, Activities, Notes, Files, Deals, Tasks
- Filter pills: All, Messages, Calls, Emails, Meetings, Notes, Stage Changes
- Timeline: vertical line with event cards (WhatsApp, Voice Call w/ waveform, Email, Meeting)
- Right panel (320px): Deal stage tracker, Lead Score 87, Next Best Action, Reminder, Payments, Ownership

The right-side chat panel connects to a live agent backend (`POST /api/agent/chat/{tenant_id}`). Each request injects live DB context (leads, skills, documents) into the LLM system prompt, and responses stream back as chat bubbles with typing indicators.

## Routing

| Route | Content |
|-------|---------|
| `/dashboard-v2` | Full dashboard page |
| Click "Home" nav | `renderDashboard()` |
| Click "Leads" nav | `renderLeads()` |
| Click lead row | `showLeadDetail(leadId)` |

## Data Flow

- Page load → `renderDashboard()` → fetch `/api/tenants/{id}/leads` → populate stats + table
- Nav click → `showPage(page)` → fetch data → replace `centerPanel.innerHTML`
- Lead row click (event delegation) → `showLeadDetail(id)` → fetch `/api/leads/{id}` → render lead card + timeline

## JavaScript Architecture

```javascript
const TENANT = '3e736242';

function showPage(page) { /* activate nav item, call render function */ }
async function renderDashboard() { /* stats + cards + table */ }
async function renderLeads() { /* list all leads */ }
async function showLeadDetail(leadId) { /* full lead card + timeline + right panel */ }

// Event delegation — never inline onclick with string args
document.getElementById('centerPanel').addEventListener('click', function(e) {
    var row = e.target.closest('.lead-row');
    if (row) showLeadDetail(row.dataset.id);
});
```

### Event Delegation Pattern (Critical)
Never use inline `onclick="functionName('arg')"` in HTML generated by Python f-strings or template strings. The quote escaping is fragile and breaks in Python triple-quoted strings. Instead:

```javascript
// BAD — breaks from Python escaping
'<tr onclick="showLeadDetail(\\'' + l.id + '\\')">'

// GOOD — never breaks
'<tr data-id="' + l.id + '" class="lead-row">'

// Add event delegation at bottom of script
document.getElementById('centerPanel').addEventListener('click', function(e) {
    var row = e.target.closest('.lead-row');
    if (row) showLeadDetail(row.dataset.id);
});
```
